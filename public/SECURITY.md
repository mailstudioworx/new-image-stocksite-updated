# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability on African Photos and Videos, please email us at security@africanphotosandvideos.com.ng.

Please do not publicly disclose the vulnerability until we have had time to address it.

## Supported Versions

We maintain security updates for the current version of our website.

## Security Measures

- Regular security audits
- HTTPS encryption for all traffic
- Content Security Policy (CSP) headers
- X-Frame-Options to prevent clickjacking
- X-Content-Type-Options to prevent MIME sniffing
- Secure cookie settings
